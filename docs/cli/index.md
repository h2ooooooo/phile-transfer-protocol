# CLI documentation

The npm client installs the `ptp` executable. It reads one YAML profile and runs the local FTP bridge until stopped.

- **Getting started:** [install through npm or download the ZIP](../guide/client-install).
- **Common tasks:** [connect an editor](../guide/editors), [switch sites](../reference/client#multiple-sites), [update the installation](../guide/updates).
- **Reference:** [commands, arguments, output and failures](./client), [YAML configuration](../reference/client).
- **Contributor tools:** the PHP compiler and source watchers are described in [development](../contributing/development) and [server reference](../reference/server#compiler-options).

For HTTP requests and integration examples, use the separate [API documentation](../api/).
