# PHP server

The PHP component is an installable Composer library and a ready-to-upload runtime ZIP. It provides the standalone HTTP endpoint and shared filesystem implementation used by the WordPress plugin.

- **Getting started:** [upload the runtime ZIP](../guide/quick-start).
- **Composer projects:** [install the package and add an entry point](./composer).
- **Common tasks:** [credentials and updates](../guide/updates), [HTTP API](../reference/api).
- **Advanced:** [compiled archives and hosting layouts](../advanced/deployment), [Docker](../advanced/docker).
- **Reference:** [runtime configuration and compiler options](../reference/server).

The WordPress ZIP bundles the PHP classes it needs. Do not install this package separately for the WordPress route.
